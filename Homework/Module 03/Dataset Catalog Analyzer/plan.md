### Ответ на вопрос: Как красиво очистить консоль (CLI-интерфейс)

Это очень правильный инженерный вопрос! Он касается взаимодействия Python с операционной системой.

**Концепция: Python и Операционная Система**
Сам по себе Python «не видит» окно твоей консоли (Терминала, PowerShell или CMD). Для Python консоль — это просто бесконечный поток текста, который он отправляет вниз (через `print()`). 
В самом языке Python нет встроенной функции `clear_screen()`, потому что разные операционные системы (Windows, Linux, macOS) используют разные внутренние команды для очистки экрана.

**Ментальная модель: Посыльный к Дворнику**
Представь, что твоя программа сидит в комнате и пишет записки (текст), которые просовывает под дверью. А за дверью стоит Дворник (Операционная Система), который выводит их на экран.
Чтобы очистить экран, Python должен написать особую записку-команду и попросить Дворника её выполнить.

**Синтаксис (Модуль `os`)**
В Python есть встроенный модуль `os` (от слова Operating System), который умеет общаться с Дворником. Команда для очистки экрана выглядит так:

```python
import os

# os.name возвращает 'nt' для Windows, и 'posix' для Linux/macOS
if os.name == 'nt':
    os.system('cls')   # Команда очистки для Windows
else:
    os.system('clear') # Команда очистки для Linux/macOS
```

Эту конструкцию принято заворачивать в одну красивую функцию, которую можно положить, например, в `main.py` или в отдельный утилитный модуль:

```python
import os

def clear_console():
    """Очищает экран консоли в зависимости от операционной системы."""
    os.system('cls' if os.name == 'nt' else 'clear')
```
*(Здесь используется тернарный оператор: `сделать_это if условие else сделать_то`. Это просто компактная запись обычного `if/else` в одну строку).*

**Где это использовать?**
Обычно `clear_console()` вызывают в цикле `while True` прямо перед тем, как нарисовать меню заново. Благодаря этому пользователь видит чистый экран с актуальным меню, а не «простыню» из старых логов и вводов.

**Инженерное предупреждение (Trade-off):**
`os.system()` — это немного «грубый» инструмент. Он на долю секунды создаёт скрытый процесс в системе, выполняет команду и закрывает его. Для нашего учебного проекта и простых утилит это **абсолютно нормальное и стандартное решение**. Но в больших профессиональных CLI-приложениях программисты используют продвинутые внешние библиотеки (например, `Rich` или `curses`), которые умеют перерисовывать текст в консоли без её полной очистки. Но это мы оставим на будущее!

1. **Общее количество картинок (`total_images`):**

2. **Среднее арифметическое (`average_images_per_dataset`):**
