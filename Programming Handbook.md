# Программа и алгоритм

## Что такое программа?

Программа --- это набор инструкций, которые компьютер выполняет для
достижения определённого результата.

Человек обычно формулирует задачу на уровне намерения:

> «Нужно обработать файлы и найти среди них нужные».

Компьютеру недостаточно такого описания.

Ему необходимо точно указать:

1.  какие данные получить;
2.  что считать нужным;
3.  какие действия выполнить;
4.  в каком порядке;
5.  что делать при нестандартных ситуациях;
6.  какой результат получить.

Поэтому программирование можно рассматривать как процесс превращения
**человеческого намерения в точную процедуру выполнения**.

------------------------------------------------------------------------

## Алгоритм

Алгоритм --- это последовательность действий, которая описывает способ
решения задачи.

Например:

``` text
Получить список файлов
        ↓
Проверить каждый файл
        ↓
Определить его категорию
        ↓
Проверить, нужен ли он
        ↓
Переместить или оставить
        ↓
Обработать нестандартные случаи
```

Алгоритм не обязан быть написан на Python.

До написания кода его можно описать:

-   обычным языком;
-   псевдокодом;
-   схемой;
-   таблицей;
-   диаграммой.

Это полезно, потому что позволяет сначала решить **логическую задачу**,
а уже затем заниматься синтаксисом.

------------------------------------------------------------------------

# Декомпозиция задач

## Что это?

Декомпозиция --- это разделение большой задачи на меньшие задачи,
которые проще понять и решить.

Вместо:

``` text
Сделать программу для обработки папки
```

можно получить:

``` text
Обработать папку
│
├── Получить список файлов
│
├── Определить тип каждого файла
│
├── Проверить критерии нужности
│
├── Обработать известные категории
│
└── Обработать нестандартные случаи
```

------------------------------------------------------------------------

## Зачем это нужно?

Большая задача часто кажется сложной не потому, что каждая её часть
сложна, а потому, что одновременно приходится удерживать слишком много
информации.

Декомпозиция уменьшает количество вещей, о которых нужно думать
одновременно.

------------------------------------------------------------------------

## Практическое правило

Если кусок задачи нельзя легко объяснить несколькими предложениями,
попробуй разделить его ещё раз.

------------------------------------------------------------------------

## Ментальная модель

Представь большую коробку с разобранной мебелью.

Не нужно пытаться собрать весь шкаф одновременно.

Сначала:

1.  разобрать детали;
2.  сгруппировать их;
3.  собрать отдельные узлы;
4.  соединить узлы;
5.  проверить результат.

Программирование работает по похожему принципу.

------------------------------------------------------------------------

# Поток данных

## Что это?

Поток данных --- это движение информации через программу.

Упрощённая модель:

``` text
INPUT
  ↓
PROCESSING
  ↓
OUTPUT
```

Например:

``` text
Файл
  ↓
Чтение текста
  ↓
Очистка
  ↓
Разбор
  ↓
Структурирование
  ↓
Готовые данные
```

------------------------------------------------------------------------

## Почему это важно?

Когда программа становится сложнее, полезно понимать не только отдельные
функции, но и вопрос:

> **Откуда пришли эти данные и куда они идут дальше?**

Например:

``` python
raw_text = read_file()
clean_text = clean(raw_text)
tags = parse_tags(clean_text)
```

Здесь поток очевиден:

``` text
raw_text
   ↓
clean_text
   ↓
tags
```

------------------------------------------------------------------------

## Практическое правило

При отладке всегда полезно спросить:

> Какое значение находится здесь прямо сейчас?

и:

> Откуда оно пришло?

------------------------------------------------------------------------

# Состояние программы

## Что такое состояние?

Состояние программы --- это информация о том, **в каком состоянии
находится программа в конкретный момент выполнения**.

Например:

``` python
score = 0
```

Состояние:

``` text
score = 0
```

После:

``` python
score += 10
```

состояние изменилось:

``` text
score = 10
```

------------------------------------------------------------------------

## Состояние может изменяться

Например:

``` python
items = []

items.append("Apple")
```

До выполнения:

``` text
items = []
```

После:

``` text
items = ["Apple"]
```

Программа продолжает работать с новым состоянием.

------------------------------------------------------------------------

## Почему это важно?

Многие программы фактически являются последовательностью изменений
состояния:

``` text
Состояние 1
    ↓
действие
    ↓
Состояние 2
    ↓
действие
    ↓
Состояние 3
```

Понимание состояния особенно важно при работе с:

-   циклами;
-   списками;
-   словарями;
-   функциями;
-   файлами;
-   пользовательским вводом.

------------------------------------------------------------------------

## Ментальная модель

Представь игру.

У неё есть:

``` text
здоровье игрока
инвентарь
позиция
очки
текущий уровень
```

Это состояние игры.

Каждое действие игрока может изменить часть этого состояния.

------------------------------------------------------------------------

# Переменные

## Что такое переменная?

Переменная --- это имя, которое позволяет обращаться к определённому
значению.

``` python
name = "Alice"
age = 20
price = 15.5
```

Здесь:

``` text
name  →  "Alice"
age   →  20
price →  15.5
```

------------------------------------------------------------------------

## Важное уточнение

Переменная --- **не само значение**.

Переменная является именем, связанным с объектом.

Поэтому полезно мыслить не так:

> «Переменная содержит число».

А так:

> «Имя `age` связано с объектом `20`».

Это различие становится особенно важным при изучении изменяемых
объектов.

------------------------------------------------------------------------

## Ментальная модель

Представь наклейку с надписью:

``` text
age
```

Наклейка прикреплена к объекту:

``` text
20
```

Если написать:

``` python
age = 25
```

мы не «изменяем наклейку».

Мы связываем имя `age` с другим объектом.

------------------------------------------------------------------------

# Присваивание

## Что делает `=`?

В Python:

``` python
=
```

--- это оператор присваивания.

Он **не означает математическое равенство**.

Например:

``` python
score = 10
```

означает:

> Связать имя `score` со значением `10`.

------------------------------------------------------------------------

## Присваивание существующего выражения

``` python
score = 10
score = score + 5
```

Во второй строке Python:

1.  получает текущее значение `score`;
2.  вычисляет `score + 5`;
3.  получает `15`;
4.  связывает `score` с новым результатом.

Получается:

``` text
score
  ↓
 15
```

------------------------------------------------------------------------

## Сокращённая форма

Вместо:

``` python
score = score + 5
```

можно написать:

``` python
score += 5
```

Аналогично:

``` python
score -= 5
score *= 2
score /= 2
```

------------------------------------------------------------------------

## Частая ошибка

Не следует воспринимать:

``` python
score = score + 5
```

как математическое уравнение.

В математике такое выражение выглядело бы противоречиво.

В программировании это последовательность:

``` text
взять старое значение
        ↓
изменить его
        ↓
связать имя с новым результатом
```

------------------------------------------------------------------------

# Типы данных

## Что такое тип?

Тип определяет, **какого рода значение находится перед нами и какие
операции с ним допустимы**.

Например:

``` python
"25"
```

и

``` python
25
```

выглядят похоже, но имеют разные типы.

Первое --- строка:

``` text
str
```

Второе --- целое число:

``` text
int
```

------------------------------------------------------------------------

## Почему типы важны?

Тип влияет на поведение объекта.

Например:

``` python
"5" + "5"
```

даёт:

``` text
"55"
```

А:

``` python
5 + 5
```

даёт:

``` text
10
```

Python не может автоматически предположить, что строку `"5"` нужно
считать числом.

------------------------------------------------------------------------

# `str`

## Что это?

`str` --- строковый тип данных.

Используется для хранения текста.

``` python
name = "Alice"
message = "Hello, world!"
filename = "image.png"
```

------------------------------------------------------------------------

## Строки могут содержать цифры

``` python
age = "25"
```

Но это всё ещё текст.

``` python
age = 25
```

--- уже число.

------------------------------------------------------------------------

## Строки неизменяемы

Строка после создания не изменяется «на месте».

Например:

``` python
text = "hello"

text.upper()
```

не изменяет исходную строку.

Метод создаёт новое значение.

Поэтому результат нужно сохранить:

``` python
text = text.upper()
```

------------------------------------------------------------------------

# `int`

## Что это?

`int` --- целое число.

``` python
age = 21
count = 10
score = -5
```

------------------------------------------------------------------------

## Примеры операций

``` python
10 + 5
10 - 5
10 * 5
10 / 5
```

Также можно использовать:

``` python
10 // 3
10 % 3
10 ** 2
```

Подробное изучение дополнительных операторов выполняется по мере
необходимости в соответствующих модулях.

------------------------------------------------------------------------

# `float`

## Что это?

`float` используется для чисел с дробной частью.

``` python
price = 12.5
temperature = 21.7
```

------------------------------------------------------------------------

## Пример

``` python
price = 10.5
quantity = 3

total = price * quantity
```

Результат:

``` text
31.5
```

------------------------------------------------------------------------

# Преобразование типов

Иногда значение необходимо преобразовать из одного типа в другой.

Основные функции:

``` python
int()
float()
str()
```

------------------------------------------------------------------------

## Строка → число

``` python
age = int("25")
```

Теперь:

``` text
age
```

имеет тип:

``` text
int
```

------------------------------------------------------------------------

## Строка → дробное число

``` python
price = float("12.5")
```

------------------------------------------------------------------------

## Число → строка

``` python
age = 25
text = str(age)
```

Теперь:

``` text
text
```

содержит строку:

``` text
"25"
```

------------------------------------------------------------------------

## Важная связь с `input()`

`input()` всегда возвращает строку.

Поэтому:

``` python
age = input("Age: ")
```

даже если пользователь введёт:

``` text
25
```

переменная `age` будет содержать:

``` text
"25"
```

Если нужно число:

``` python
age = int(input("Age: "))
```

# Изменяемые и неизменяемые объекты

Это одна из наиболее важных концепций, изученных к концу Module 02.

------------------------------------------------------------------------

## Неизменяемые объекты

К изученным неизменяемым типам относятся:

-   `str`;
-   `int`;
-   `float`.

Если необходимо получить изменённую версию, создаётся новое значение.

Например:

``` python
text = "hello"

text = text.upper()
```

Метод `upper()` не изменяет существующую строку.

Он возвращает новую строку.

------------------------------------------------------------------------

## Изменяемые объекты

К изученным изменяемым коллекциям относятся:

-   `list`;
-   `dict`;
-   `set`.

Их содержимое можно изменить после создания.

Например:

``` python
items = ["Apple"]

items.append("Banana")
```

Теперь:

``` python
items
```

содержит:

``` text
["Apple", "Banana"]
```

------------------------------------------------------------------------

## Почему это важно для функций?

Рассмотрим:

``` python
def add_item(items):
    items.append("Apple")
```

Если передать список:

``` python
items = []

add_item(items)
```

список изменится.

Почему?

Потому что функция работает с тем же изменяемым объектом.

------------------------------------------------------------------------

## Сравнение

### Неизменяемый объект

``` python
def make_upper(text):
    text = text.upper()
```

Внешняя строка сама по себе не изменяется.

Чтобы получить результат:

``` python
def make_upper(text):
    return text.upper()
```

------------------------------------------------------------------------

### Изменяемый объект

``` python
def add_item(items):
    items.append("Apple")
```

Возвращать список необязательно, если задача функции --- изменить
переданный список.

------------------------------------------------------------------------

## Важное уточнение

Не следует запоминать это как:

> «Списки передаются по ссылке, а строки --- нет».

Более точная модель:

> Python передаёт в функцию ссылку на объект. Если объект изменяемый,
> функция может изменить этот объект. Если объект неизменяемый, изменить
> сам объект невозможно --- можно только создать новый.

Эта концепция станет ещё важнее при дальнейшем изучении объектов, ссылок
и областей видимости.

------------------------------------------------------------------------

# Коллекции данных

## Что такое коллекция?

Коллекция --- это структура, предназначенная для хранения нескольких
значений.

В изученных темах используются:

  Тип       Основная идея
  --------- -----------------------------------------------
  `list`    Упорядоченная последовательность
  `tuple`   Упорядоченная неизменяемая последовательность
  `dict`    Связь ключ → значение
  `set`     Уникальные элементы

У каждой структуры своя задача.

------------------------------------------------------------------------

# Списки

## Что такое список?

`list` --- изменяемая упорядоченная коллекция.

``` python
fruits = ["Apple", "Banana", "Orange"]
```

------------------------------------------------------------------------

## Главные свойства

Список:

-   хранит несколько элементов;
-   сохраняет порядок;
-   допускает повторения;
-   поддерживает индексы;
-   является изменяемым.

------------------------------------------------------------------------

## Ментальная модель

Представь пронумерованную полку:

``` text
0 → Apple
1 → Banana
2 → Orange
```

Каждый элемент имеет позицию.

------------------------------------------------------------------------

# Индексы

## Что такое индекс?

Индекс --- это позиция элемента внутри последовательности.

Python начинает индексацию с `0`.

``` python
fruits = ["Apple", "Banana", "Orange"]
```

Получаем:

``` text
fruits[0] → "Apple"
fruits[1] → "Banana"
fruits[2] → "Orange"
```

------------------------------------------------------------------------

## Почему индексация начинается с нуля?

Для практического использования достаточно помнить:

> Первый элемент имеет индекс `0`.

Исторические и технические причины этого решения относятся к более
глубокому уровню устройства языков программирования и могут быть
рассмотрены отдельно.

------------------------------------------------------------------------

## Ошибка выхода за границы

Если список содержит три элемента:

``` python
fruits = ["Apple", "Banana", "Orange"]
```

то:

``` python
fruits[3]
```

вызовет ошибку, потому что такого индекса нет.

------------------------------------------------------------------------

# Основные операции со списками

## `append()`

Добавляет **один элемент** в конец списка.

``` python
items = ["Apple"]

items.append("Banana")
```

Результат:

``` python
["Apple", "Banana"]
```

### Возвращаемое значение

`append()` возвращает:

``` python
None
```

Поэтому неправильно:

``` python
items = items.append("Banana")
```

После этого `items` станет `None`.

Правильно:

``` python
items.append("Banana")
```

------------------------------------------------------------------------

## `extend()`

Добавляет элементы другой коллекции в конец списка.

``` python
numbers = [1, 2]
numbers.extend([3, 4])
```

Результат:

``` python
[1, 2, 3, 4]
```

### `append()` против `extend()`

`append()` добавляет **один объект целиком**:

``` python
items = [1, 2]
items.append([3, 4])
```

Результат:

``` python
[1, 2, [3, 4]]
```

Список `[3, 4]` стал одним элементом.

`extend()` добавляет элементы другой коллекции по отдельности:

``` python
items = [1, 2]
items.extend([3, 4])
```

Результат:

``` python
[1, 2, 3, 4]
```

### Ментальная модель

`append()` кладёт одну коробку на полку.

`extend()` открывает коробку и высыпает её содержимое на полку.

------------------------------------------------------------------------

## `insert()`

Добавляет элемент на указанную позицию.

``` python
colors = ["Red", "Blue"]
colors.insert(1, "Green")
```

Результат:

``` python
["Red", "Green", "Blue"]
```

Первый аргумент --- индекс позиции, куда вставить элемент. Элементы,
начиная с этой позиции, сдвигаются вправо.

------------------------------------------------------------------------

## `pop()`

Удаляет элемент по индексу и **возвращает удалённый элемент**.

``` python
tasks = ["A", "B", "C"]
last = tasks.pop()
```

Теперь:

``` text
tasks → ["A", "B"]
last  → "C"
```

Можно указать индекс:

``` python
tasks.pop(0)
```

Если индекс не указан, удаляется последний элемент.

Это важное отличие от большинства изменяющих методов списка: `pop()`
изменяет список и одновременно возвращает удалённый элемент.

------------------------------------------------------------------------

## `clear()`

Удаляет все элементы из списка.

``` python
errors = ["File not found", "Invalid format"]
errors.clear()
```

После этого:

``` python
[]
```

Сам объект списка продолжает существовать --- он просто становится
пустым.

------------------------------------------------------------------------

## `reverse()`

Разворачивает порядок элементов списка на месте.

``` python
letters = ["A", "B", "C"]
letters.reverse()
```

Результат:

``` python
["C", "B", "A"]
```

------------------------------------------------------------------------

## Возвращаемые значения изменяющих методов

Большинство изученных методов списка, которые изменяют список на месте,
возвращают `None`:

``` text
append()
extend()
insert()
remove()
clear()
sort()
reverse()
```

Исключение среди изученных методов --- `pop()`: он изменяет список и
возвращает удалённый элемент.

Поэтому неправильно:

``` python
items = items.append("Apple")
```

После этого `items` станет `None`.

Правильно:

``` python
items.append("Apple")
```

Список уже изменён, поэтому повторное присваивание не требуется.

------------------------------------------------------------------------

## `remove()`

Удаляет элемент по его значению.

``` python
items = ["Apple", "Banana"]

items.remove("Apple")
```

Получаем:

``` python
["Banana"]
```

Если указанного элемента нет, операция вызывает ошибку.

------------------------------------------------------------------------

## `sort()`

Сортирует список на месте.

``` python
numbers = [5, 2, 8, 1]

numbers.sort()
```

Теперь:

``` python
[1, 2, 5, 8]
```

В отличие от встроенной функции `sorted()`, метод `sort()` изменяет сам
список.

------------------------------------------------------------------------

------------------------------------------------------------------------

# Кортежи

## Что такое кортеж?

`tuple` --- упорядоченная последовательность, которую после создания
нельзя изменять.

``` python
point = (10, 20)
```

------------------------------------------------------------------------

## Главное отличие от списка

Список:

``` python
items = [1, 2, 3]
```

можно изменить.

Кортеж:

``` python
items = (1, 2, 3)
```

изменить нельзя.

------------------------------------------------------------------------

## Зачем нужен кортеж?

Кортеж подходит для данных, которые логически представляют одну
фиксированную группу значений.

Например:

``` python
point = (10, 20)
```

Координаты точки обычно не должны случайно превращаться в список с
другим количеством элементов.

------------------------------------------------------------------------

# Словари

## Что такое словарь?

`dict` --- изменяемая коллекция, хранящая связи:

``` text
Ключ → Значение
```

Например:

``` python
student = {
    "name": "Alice",
    "age": 20,
    "grade": 5
}
```

------------------------------------------------------------------------

## Почему словари важны?

Представим данные, которые хранятся в параллельных списках:

``` python
names = ["Alice", "Bob", "Charlie"]
ages = [20, 21, 19]
```

Теперь нужно постоянно помнить, что:

``` text
names[0] соответствует ages[0]
names[1] соответствует ages[1]
names[2] соответствует ages[2]
```

Это хрупкая архитектура.

Словарь позволяет объединить связанные данные:

``` python
students = {
    "Alice": 20,
    "Bob": 21,
    "Charlie": 19
}
```

Теперь связь выражена непосредственно структурой данных.

------------------------------------------------------------------------

## Доступ по ключу

``` python
students["Alice"]
```

Результат:

``` text
20
```

------------------------------------------------------------------------

## Изменение значения

``` python
students["Alice"] = 21
```

------------------------------------------------------------------------

## Добавление значения

``` python
students["David"] = 22
```

------------------------------------------------------------------------

## Ментальная модель

Представь картотеку.

На каждой карточке есть:

``` text
Ключ
 ↓
Информация
```

Ключ позволяет быстро найти соответствующее значение.

------------------------------------------------------------------------

## Вложенные словари

Значением словаря может быть другой словарь.

``` python
students = {
    "Alice": {
        "age": 20,
        "grade": 5
    },
    "Bob": {
        "age": 21,
        "grade": 4
    }
}
```

Теперь:

``` python
students["Alice"]["age"]
```

даёт:

``` text
20
```

------------------------------------------------------------------------

# Методы словарей

Словарь имеет набор методов, которые позволяют работать с его ключами и
значениями.

## `.items()`

Возвращает пары **(ключ, значение)**. Особенно полезен при переборе
словаря.

``` python
students = {
    "Alice": 20,
    "Bob": 21,
    "Charlie": 19
}

for name, age in students.items():
    print(name, age)
```

Результат:

``` text
Alice 20
Bob 21
Charlie 19
```

### Ментальная модель

`.items()` открывает каждую карточку картотеки и показывает одновременно
её наклейку (ключ) и содержимое (значение).

------------------------------------------------------------------------

## `.keys()`

Возвращает представление ключей словаря.

``` python
for name in students.keys():
    print(name)
```

Результат:

``` text
Alice
Bob
Charlie
```

При обычном переборе словаря ключи и так перебираются напрямую:

``` python
for name in students:
    print(name)
```

Поэтому `.keys()` полезен прежде всего тогда, когда хочется явно
подчеркнуть, что нас интересуют именно ключи.

------------------------------------------------------------------------

## `.values()`

Возвращает представление значений словаря.

``` python
for age in students.values():
    print(age)
```

Результат:

``` text
20
21
19
```

------------------------------------------------------------------------

## `.get()`

Позволяет безопасно получить значение по ключу.

Обычный доступ:

``` python
students["David"]
```

вызовет `KeyError`, если ключа `"David"` нет.

Безопасный доступ:

``` python
students.get("David")
```

вернёт `None`, если ключ отсутствует.

Можно указать значение по умолчанию:

``` python
students.get("David", 0)
```

В этом случае будет возвращено `0`, если ключа нет.

### Когда использовать `.get()`?

Используй `.get()`, когда ключ **может отсутствовать** и это нормальная
ситуация.

Используй обычный доступ через `[]`, когда ключ **обязательно должен
существовать** и отсутствие ключа должно считаться ошибкой.

------------------------------------------------------------------------

## Проверка наличия ключа через `in`

Оператор `in` при работе со словарём проверяет наличие **ключа**:

``` python
if "Alice" in students:
    print("Found")
```

Это не то же самое, что проверка значений. Для проверки значений можно
использовать `.values()`:

``` python
if 20 in students.values():
    print("Found")
```

------------------------------------------------------------------------

## Типичная ошибка: `.add()` у словаря

`.add()` --- метод множества, а не словаря.

Неправильно:

``` python
students.add("David")
```

Для добавления или изменения значения в словаре используется
присваивание по ключу:

``` python
students["David"] = 22
```

------------------------------------------------------------------------

# Множества

## Что такое `set`?

`set` --- изменяемая коллекция уникальных элементов.

``` python
tags = {"python", "programming", "data"}
```

------------------------------------------------------------------------

## Главные свойства

Множество:

-   не хранит дубликаты;
-   не предназначено для доступа по индексу;
-   удобно для проверки принадлежности;
-   удобно для дедупликации;
-   основано на хешировании.

------------------------------------------------------------------------

## Ментальная модель

Представь VIP-клуб.

На входе стоит охранник.

Если человек уже есть в списке:

``` text
Он уже внутри.
```

Повторно добавить его нельзя.

Поэтому:

``` python
tags = {"python", "python", "data"}
```

фактически представляет:

``` python
{"python", "data"}
```

------------------------------------------------------------------------

## Создание пустого множества

Важно:

``` python
set()
```

создаёт пустое множество.

А:

``` python
{}
```

создаёт **пустой словарь**, а не множество.

------------------------------------------------------------------------

## Добавление элемента

Используется:

``` python
tags.add("python")
```

а не:

``` python
tags.append("python")
```

Потому что `append()` --- метод списка.

------------------------------------------------------------------------

## Проверка принадлежности

``` python
if "python" in tags:
    print("Found")
```

Проверка принадлежности --- одно из главных назначений множества.

------------------------------------------------------------------------

## Удаление дубликатов

Очень полезный паттерн:

``` python
unique_items = set(items)
```

Например:

``` python
items = ["A", "B", "A", "C", "B"]

unique_items = set(items)
```

Получим множество уникальных значений:

``` python
{"A", "B", "C"}
```

------------------------------------------------------------------------

## Когда использовать `set`

Используй множество, когда:

-   нужны только уникальные значения;
-   часто проверяется наличие элемента;
-   нужно быстро убрать дубликаты;
-   нужны операции над множествами.

------------------------------------------------------------------------

## Когда не использовать `set`

Не используй множество, если:

-   порядок элементов имеет значение;
-   нужны повторяющиеся значения;
-   нужен доступ по индексу.

------------------------------------------------------------------------

  --------------------------------------------------------------------------------
  Свойство         `list`               `tuple`         `dict`      `set`
  ---------------- -------------------- --------------- ----------- --------------
  Изменяемый       Да                   Нет             Да          Да

  Порядок          Да                   Да              Да\*        Нет

  Индексы          Да                   Да              Нет         Нет

  Дубликаты        Да                   Да              Ключи ---   Нет
                                                        нет         

  Ключ → значение  Нет                  Нет             Да          Нет

  Проверка         Да                   Да              Да          Да
  принадлежности

  назначение                            группа          данные      поиск
  --------------------------------------------------------------------------------

-   В современных версиях Python словари сохраняют порядок добавления
    ключей, однако словарь всё равно следует рассматривать прежде всего
    как структуру **ключ → значение**, а не как замену списку.

# Комментарии

## Что это?

Комментарий --- это текст в исходном коде, который Python не выполняет.

Однострочный комментарий начинается с `#`:

``` python
# Это комментарий
name = "Alice"
```

Комментарий можно написать после инструкции:

``` python
name = "Alice"  # Имя пользователя
```

------------------------------------------------------------------------

## Зачем нужны комментарии?

Комментарии используются для:

-   объяснения сложного участка кода;
-   фиксации важного решения;
-   временного отключения строки кода;
-   пояснения причины нестандартного решения.

Однако комментарии не должны просто повторять очевидный код.

Плохо:

``` python
age = 20  # Создаём переменную age и присваиваем ей 20
```

Лучше:

``` python
# Возраст приходит из внешнего API в месяцах.
age = age_in_months / 12
```

Комментарий должен объяснять **почему**, когда это не очевидно из самого
кода.

------------------------------------------------------------------------

# Выражения и инструкции

## Выражение

Выражение --- это конструкция, которую Python может вычислить и получить
из неё значение.

Например:

``` python
2 + 3
```

Результат:

``` text
5
```

Или:

``` python
name.upper()
```

Результатом будет новое значение строки.

------------------------------------------------------------------------

## Инструкция

Инструкция --- это действие, которое Python должен выполнить.

Например:

``` python
name = "Alice"
```

Это инструкция присваивания.

Другие примеры:

``` python
print(name)

if age >= 18:
    ...

for item in items:
    ...
```

На практике важно понимать разницу между:

> **вычислить значение**

и

> **выполнить действие**.

Эта разница станет особенно полезной при изучении функций.

------------------------------------------------------------------------

# Операторы

Оператор --- это специальный синтаксис, обозначающий операцию над
значениями.

Например:

``` python
+
-
*
/
==
>
<
```

------------------------------------------------------------------------

## Арифметические операторы

``` python
a + b
a - b
a * b
a / b
```

Дополнительно:

``` python
a // b
a % b
a ** b
```

### `/`

Обычное деление:

``` python
10 / 3
```

Результат:

``` text
3.333333...
```

### `//`

Целочисленное деление:

``` python
10 // 3
```

Результат:

``` text
3
```

### `%`

Остаток от деления:

``` python
10 % 3
```

Результат:

``` text
1
```

### `**`

Возведение в степень:

``` python
2 ** 3
```

Результат:

``` text
8
```

------------------------------------------------------------------------

# Операторы сравнения

Операторы сравнения сравнивают значения и возвращают `True` или `False`.

``` python
a == b
a != b
a > b
a < b
a >= b
a <= b
```

------------------------------------------------------------------------

## `==`

Проверяет равенство:

``` python
age == 18
```

------------------------------------------------------------------------

## `!=`

Проверяет неравенство:

``` python
age != 18
```

------------------------------------------------------------------------

## `>`

``` python
age > 18
```

------------------------------------------------------------------------

## `<`

``` python
age < 18
```

------------------------------------------------------------------------

## `>=`

``` python
age >= 18
```

Означает:

> больше или равно.

------------------------------------------------------------------------

## `<=`

``` python
age <= 18
```

Означает:

> меньше или равно.

------------------------------------------------------------------------

## Важнейшая ошибка: `=` и `==`

Это разные операторы.

``` python
age = 18
```

означает:

> присвоить.

А:

``` python
age == 18
```

означает:

> проверить равенство.

# Логические значения

В Python существуют два специальных значения:

``` python
True
False
```

Они представляют результат логического утверждения.

Например:

``` python
age = 20

age >= 18
```

даёт:

``` text
True
```

------------------------------------------------------------------------

# Логические операторы

Python позволяет объединять условия.

Основные операторы:

``` python
and
or
not
```

------------------------------------------------------------------------

## `and`

Оба условия должны быть истинными.

``` python
age >= 18 and has_ticket
```

Истина только тогда, когда:

``` text
age >= 18     → True
has_ticket    → True
```

------------------------------------------------------------------------

## `or`

Достаточно одного истинного условия.

``` python
is_admin or is_owner
```

------------------------------------------------------------------------

## `not`

Инвертирует логическое значение.

``` python
not is_admin
```

Если:

``` text
is_admin → True
```

то:

``` text
not is_admin → False
```

------------------------------------------------------------------------

# Условия

## Что такое условие?

Условная конструкция позволяет программе выбрать разные действия в
зависимости от ситуации.

``` python
if condition:
    do_something()
```

Например:

``` python
age = 20

if age >= 18:
    print("Adult")
```

------------------------------------------------------------------------

## `if`

``` python
if age >= 18:
    print("Adult")
```

Если условие истинно, блок выполняется.

------------------------------------------------------------------------

## `else`

``` python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

Если условие ложно, выполняется `else`.

------------------------------------------------------------------------

## `elif`

Используется для нескольких вариантов.

``` python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"
```

Python проверяет условия сверху вниз.

Как только найдено первое истинное условие, соответствующий блок
выполняется, а остальные пропускаются.

------------------------------------------------------------------------

## Вложенные условия

Условия можно помещать внутрь других условий:

``` python
if user_exists:
    if user_is_active:
        print("Access granted")
```

Но чрезмерная вложенность ухудшает читаемость.

Иногда лучше использовать логический оператор:

``` python
if user_exists and user_is_active:
    print("Access granted")
```

------------------------------------------------------------------------

# Отступы

В Python отступы являются частью синтаксиса.

Например:

``` python
if age >= 18:
    print("Adult")
```

`print()` принадлежит блоку `if`.

Без отступа:

``` python
if age >= 18:
print("Adult")
```

код некорректен.

------------------------------------------------------------------------

## Рекомендуемый стиль

Обычно используется **4 пробела** для одного уровня вложенности.

``` python
if condition:
    do_something()
```

Не следует смешивать табы и пробелы.

------------------------------------------------------------------------

# Ввод данных

## `input()`

`input()` позволяет получить данные от пользователя.

``` python
name = input("Enter your name: ")
```

Пользователь вводит:

``` text
Alice
```

После этого:

``` python
name
```

равно:

``` text
"Alice"
```

------------------------------------------------------------------------

## Важное правило

`input()` всегда возвращает `str`.

Даже если пользователь вводит:

``` text
25
```

результат:

``` python
age = input("Age: ")
```

будет:

``` text
"25"
```

а не:

``` text
25
```

------------------------------------------------------------------------

## Получение числа

``` python
age = int(input("Age: "))
```

Или:

``` python
price = float(input("Price: "))
```

------------------------------------------------------------------------

## Очистка пользовательского ввода

Если пользователь может ввести лишние пробелы:

``` python
name = input("Name: ").strip()
```

Теперь:

``` text
"  Alice  "
```

превратится в:

``` text
"Alice"
```

Это пример общего принципа:

> **Очищай данные на границе системы.**

------------------------------------------------------------------------

# Вывод данных

## `print()`

`print()` выводит информацию.

``` python
print("Hello")
```

Можно передавать несколько аргументов:

``` python
print("Name:", name)
```

------------------------------------------------------------------------

## `print()` не является способом вернуть результат функции

Это фундаментальное различие.

``` python
def add(a, b):
    print(a + b)
```

Эта функция выводит результат пользователю.

Но сама программа не получает результат через `return`.

Правильнее:

``` python
def add(a, b):
    return a + b
```

Теперь:

``` python
result = add(2, 3)
```

и:

``` python
print(result)
```

------------------------------------------------------------------------

# f-строки

## Что это?

f-string позволяет удобно вставлять значения переменных внутрь текста.

``` python
name = "Alice"
age = 20

message = f"{name} is {age} years old."
```

Результат:

``` text
Alice is 20 years old.
```

------------------------------------------------------------------------

## Синтаксис

Перед строкой ставится `f`:

``` python
f"Текст {expression}"
```

Например:

``` python
price = 10
quantity = 3

message = f"Total: {price * quantity}"
```

------------------------------------------------------------------------

## Почему f-строки удобны?

Без них пришлось бы отдельно соединять части строки или преобразовывать
числа в текст.

f-string позволяет писать выражение непосредственно внутри `{}`.

# Часть III. Управление выполнением

------------------------------------------------------------------------

# Циклы

## Что такое цикл?

Цикл позволяет выполнять один и тот же блок кода несколько раз.

Например, если необходимо обработать 100 файлов, не нужно писать одну и
ту же инструкцию 100 раз.

Можно описать:

``` text
для каждого файла:
    обработать файл
```

В Python это обычно реализуется через `for`.

------------------------------------------------------------------------

# Цикл `for`

## Базовый синтаксис

``` python
for item in collection:
    process(item)
```

Например:

``` python
fruits = ["Apple", "Banana", "Orange"]

for fruit in fruits:
    print(fruit)
```

Python последовательно присвоит переменной `fruit` каждый элемент
списка.

------------------------------------------------------------------------

## Ментальная модель

Представь конвейер:

``` text
Apple
   ↓
обработка

Banana
   ↓
обработка

Orange
   ↓
обработка
```

Переменная цикла временно представляет текущий элемент.

------------------------------------------------------------------------

## Имя переменной

Обычно используется имя, описывающее текущий элемент:

``` python
for file in files:
```

лучше, чем:

``` python
for x in files:
```

Хорошее имя уменьшает необходимость в комментариях.

------------------------------------------------------------------------

# `range()`

`range()` создаёт последовательность чисел, которую часто используют в
циклах.

``` python
for i in range(5):
    print(i)
```

Результат:

``` text
0
1
2
3
4
```

Обрати внимание:

> `5` не входит в последовательность.

------------------------------------------------------------------------

## `range(start, stop)`

``` python
range(2, 5)
```

даёт:

``` text
2
3
4
```

------------------------------------------------------------------------

## `range(start, stop, step)`

``` python
range(0, 10, 2)
```

даёт:

``` text
0
2
4
6
8
```

------------------------------------------------------------------------

# Цикл `while`

`while` повторяет блок кода, пока условие истинно.

``` python
while condition:
    do_something()
```

Например:

``` python
count = 0

while count < 5:
    print(count)
    count += 1
```

------------------------------------------------------------------------

## Когда использовать `while`?

`while` особенно полезен, когда количество повторений заранее
неизвестно.

Например:

``` text
спрашивать пароль,
пока пароль не станет правильным.
```

------------------------------------------------------------------------

## Бесконечный цикл

Такой код:

``` python
while True:
    print("Hello")
```

будет выполняться бесконечно, если внутри нет механизма выхода.

Часто используется:

``` python
while True:
    command = input("> ")

    if command == "exit":
        break
```

------------------------------------------------------------------------

# `break`

`break` немедленно прекращает текущий цикл.

``` python
for item in items:
    if item == "STOP":
        break

    process(item)
```

Как только встретится `"STOP"`, цикл закончится.

------------------------------------------------------------------------

## Ментальная модель

`break` означает:

> «Мы больше не хотим продолжать этот цикл».

------------------------------------------------------------------------

# `continue`

`continue` пропускает оставшуюся часть текущей итерации и переходит к
следующей.

``` python
for number in numbers:
    if number < 0:
        continue

    print(number)
```

Отрицательные числа не будут обработаны.

------------------------------------------------------------------------

# `enumerate()`

Иногда при переборе списка нужны одновременно:

-   сам элемент;
-   его индекс.

Вместо:

``` python
for i in range(len(items)):
    print(i, items[i])
```

можно использовать:

``` python
for i, item in enumerate(items):
    print(i, item)
```

------------------------------------------------------------------------

## Пример

``` python
fruits = ["Apple", "Banana", "Orange"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

Получим:

``` text
0 Apple
1 Banana
2 Orange
```

------------------------------------------------------------------------

## Почему `enumerate()` предпочтительнее?

Он явно выражает намерение:

> «Мне нужен индекс и соответствующий элемент».

Это обычно читается лучше, чем ручная работа с `range(len(...))`.

------------------------------------------------------------------------

# `zip()`

`zip()` позволяет одновременно перебирать несколько последовательностей.

Например:

``` python
names = ["Alice", "Bob", "Charlie"]
ages = [20, 21, 19]
```

Можно написать:

``` python
for name, age in zip(names, ages):
    print(name, age)
```

Получаем:

``` text
Alice 20
Bob 21
Charlie 19
```

------------------------------------------------------------------------

## Почему это важно?

Ранее мы рассматривали проблему **параллельных списков**.

`zip()` делает работу с ними удобнее, но не устраняет саму архитектурную
проблему.

Если данные логически принадлежат одной сущности, часто лучше
использовать словарь или другую структуру:

``` python
students = {
    "Alice": 20,
    "Bob": 21,
    "Charlie": 19
}
```

Поэтому `zip()` --- полезный инструмент, но не повод создавать
параллельные списки там, где можно использовать более подходящую модель
данных.

------------------------------------------------------------------------

# Часть IV. Функции

------------------------------------------------------------------------

# Что такое функция?

Функция --- это именованный блок кода, который выполняет определённую
задачу.

Например:

``` python
def greet(name):
    return f"Hello, {name}!"
```

После этого функцию можно вызвать:

``` python
message = greet("Alice")
```

------------------------------------------------------------------------

## Ментальная модель

Функцию удобно представлять как **чёрный ящик**:

``` text
       INPUT
         ↓
┌─────────────────┐
│     FUNCTION    │
│                 │
│     обработка   │
│                 │
└─────────────────┘
         ↓
       OUTPUT
```

Нас интересует:

1.  какие данные функция принимает;
2.  что она делает;
3.  что возвращает.

Внутренняя реализация может быть скрыта.

------------------------------------------------------------------------

# Определение функции

``` python
def function_name(parameters):
    # тело функции
    ...
```

Например:

``` python
def add(a, b):
    return a + b
```

------------------------------------------------------------------------

## Вызов функции

``` python
result = add(2, 3)
```

Внутри функции:

``` text
a = 2
b = 3
```

Результат:

``` text
5
```

возвращается вызывающему коду.

------------------------------------------------------------------------

# Параметры и аргументы

Эти термины часто путают.

``` python
def greet(name):
    return f"Hello, {name}"
```

`name` --- **параметр**.

При вызове:

``` python
greet("Alice")
```

`"Alice"` --- **аргумент**.

------------------------------------------------------------------------

## Ментальная модель

Параметр --- это условное место:

``` text
name → ?
```

Аргумент --- конкретное значение:

``` text
name → "Alice"
```

------------------------------------------------------------------------

# `return`

`return` завершает выполнение функции и передаёт значение обратно
вызывающему коду.

``` python
def add(a, b):
    return a + b
```

При:

``` python
result = add(2, 3)
```

происходит:

``` text
2 + 3
   ↓
5
   ↓
return
   ↓
result
```

------------------------------------------------------------------------

## После `return` функция прекращает выполнение

``` python
def test():
    return 10
    print("Hello")
```

`print()` никогда не выполнится.

------------------------------------------------------------------------

# `print()` против `return`

Это одно из важнейших различий.

### `print()`

Сообщает информацию человеку:

``` python
print(result)
```

### `return`

Передаёт результат другой части программы:

``` python
return result
```

------------------------------------------------------------------------

## Пример

Плохо, если функция должна быть универсальным вычислителем:

``` python
def calculate(a, b):
    print(a + b)
```

Лучше:

``` python
def calculate(a, b):
    return a + b
```

Теперь результат можно:

``` python
result = calculate(10, 20)
```

использовать дальше:

``` python
if result > 25:
    ...
```

или:

``` python
total = calculate(10, 20) + 5
```

------------------------------------------------------------------------

# Функция без `return`

Функция может ничего явно не возвращать.

``` python
def greet(name):
    print(f"Hello, {name}")
```

Если функция не выполняет `return` с другим значением, её результатом
является:

``` python
None
```

------------------------------------------------------------------------

# `None`

`None` означает отсутствие значения.

Например:

``` python
result = None
```

Это не:

-   `0`;
-   `False`;
-   `""`.

Это отдельное специальное значение.

------------------------------------------------------------------------

# Область действия функций

Переменная, созданная внутри функции, обычно существует только внутри
неё.

``` python
def calculate():
    result = 10
    return result
```

Здесь `result` --- локальная переменная.

После завершения функции нельзя просто обратиться к ней снаружи:

``` python
print(result)
```

------------------------------------------------------------------------

## Почему это полезно?

Локальные переменные помогают изолировать внутреннее состояние функции.

Это поддерживает принцип:

> **Функция должна знать только то, что ей действительно необходимо.**

------------------------------------------------------------------------

# Глобальные переменные

Переменная, созданная вне функции:

``` python
tax = 0.2
```

может быть доступна внутри функции:

``` python
def calculate(price):
    return price * tax
```

Но чрезмерная зависимость функций от глобальных переменных делает код
сложнее для понимания и тестирования.

Предпочтительнее явно передавать необходимые данные:

``` python
def calculate(price, tax):
    return price * tax
```

Теперь функция становится более независимой.

------------------------------------------------------------------------

# Функция как независимый компонент

Хорошая функция должна по возможности иметь понятный контракт:

``` text
Вход:
    что принимает?

Обработка:
    что делает?

Выход:
    что возвращает?
```

Например:

``` python
def calculate_total(price, quantity):
    return price * quantity
```

Контракт:

``` text
Вход:
    price
    quantity

Действие:
    умножение

Выход:
    total
```

------------------------------------------------------------------------

# Передача изменяемых объектов в функции

Рассмотрим:

``` python
def add_item(items):
    items.append("Apple")
```

И:

``` python
items = []

add_item(items)
```

После вызова:

``` python
items
```

содержит:

``` python
["Apple"]
```

------------------------------------------------------------------------

## Почему?

Потому что `items` внутри функции и `items` снаружи относятся к одному
объекту списка.

Функция может изменить этот объект.

------------------------------------------------------------------------

## Неизменяемый объект

Рассмотрим строку:

``` python
def make_upper(text):
    text.upper()
```

Исходная строка не изменится.

Нужно вернуть новый объект:

``` python
def make_upper(text):
    return text.upper()
```

И использовать:

``` python
text = make_upper(text)
```

------------------------------------------------------------------------

# Предсказуемость возвращаемого значения

Функция должна иметь понятный и стабильный контракт.

Плохой пример:

``` python
def parse_data(data):
    if not data:
        return None

    return name, age
```

Вызывающий код может ожидать два значения:

``` python
name, age = parse_data(data)
```

Но при пустых данных получит:

``` python
None
```

и программа завершится ошибкой распаковки.

------------------------------------------------------------------------

## Более надёжный принцип

Функция должна возвращать результат в предсказуемом формате.

Например, можно всегда возвращать пару:

``` python
def parse_data(data):
    if not data:
        return None, None

    return name, age
```

Или использовать другую единую структуру результата.

Главное:

> **Контракт функции должен быть предсказуемым для вызывающего кода.**

------------------------------------------------------------------------

# Часть V. Встроенные инструменты Python

Python уже содержит большое количество готовых инструментов.

Не следует автоматически писать собственную реализацию задачи, если язык
уже предоставляет подходящую функцию.

Это можно сформулировать как:

> **Toolbox Rule №1: сначала проверь, нет ли готового инструмента.**

------------------------------------------------------------------------

# Функция или метод?

Это важное различие.

## Функция

Функция вызывается самостоятельно:

``` python
len(items)
sum(numbers)
```

------------------------------------------------------------------------

## Метод

Метод вызывается у конкретного объекта:

``` python
items.append("Apple")
text.upper()
```

Ментальная модель:

``` text
Функция:
    действие(объект)

Метод:
    объект.действие()
```

Например:

``` python
len(items)
```

и:

``` python
items.append("Apple")
```

------------------------------------------------------------------------

# `len()`

`len()` возвращает количество элементов.

``` python
items = ["A", "B", "C"]

len(items)
```

Результат:

``` text
3
```

Работает с разными объектами:

``` python
len("Hello")
len([1, 2, 3])
len({"a": 1, "b": 2})
```

------------------------------------------------------------------------

# `sum()`

`sum()` складывает элементы числовой последовательности.

``` python
numbers = [10, 20, 30]

total = sum(numbers)
```

Результат:

``` text
60
```

------------------------------------------------------------------------

## Типичная ошибка

Не нужно вручную писать:

``` python
total = 0

for number in numbers:
    total += number
```

если нужна просто сумма.

Такой цикл полезен для обучения или когда необходимо выполнить
дополнительную логику.

Но для обычного суммирования:

``` python
sum(numbers)
```

проще и понятнее.

------------------------------------------------------------------------

# `min()` и `max()`

Возвращают минимальное и максимальное значение.

``` python
numbers = [5, 2, 9, 1]

minimum = min(numbers)
maximum = max(numbers)
```

Результат:

``` text
minimum → 1
maximum → 9
```

------------------------------------------------------------------------

# `sorted()`

`sorted()` возвращает **новую отсортированную последовательность**.

``` python
numbers = [5, 2, 9, 1]

sorted_numbers = sorted(numbers)
```

Исходный список не изменяется:

``` text
numbers        → [5, 2, 9, 1]
sorted_numbers → [1, 2, 5, 9]
```

------------------------------------------------------------------------

## `sorted()` против `.sort()`

``` python
sorted(numbers)
```

создаёт новый результат.

А:

``` python
numbers.sort()
```

изменяет сам список.

Это хороший пример различия между:

> функцией, возвращающей новый объект,

и:

> методом, изменяющим существующий объект.

------------------------------------------------------------------------

# Часть VI. Методы строк

------------------------------------------------------------------------

# `lower()`

Переводит буквы строки в нижний регистр.

``` python
text = "Hello World"

result = text.lower()
```

Результат:

``` text
hello world
```

Исходная строка не изменяется.

------------------------------------------------------------------------

# `upper()`

Переводит буквы в верхний регистр.

``` python
text = "Hello"

result = text.upper()
```

Результат:

``` text
HELLO
```

------------------------------------------------------------------------

# `strip()`

Удаляет пробельные символы с начала и конца строки.

``` python
text = "   Hello   "

clean = text.strip()
```

Результат:

``` text
"Hello"
```

------------------------------------------------------------------------

## Практическое применение

Очень полезен при чтении внешних данных:

``` python
name = input("Name: ").strip()
```

Это позволяет нормализовать данные сразу после их получения.

------------------------------------------------------------------------

# `replace()`

Заменяет одну часть строки другой.

``` python
text = "Hello world"

result = text.replace("world", "Python")
```

Получаем:

``` text
Hello Python
```

Строка не изменяется на месте.

------------------------------------------------------------------------

# `split()`

Разбивает строку на список строк.

``` python
text = "apple,banana,orange"

items = text.split(",")
```

Результат:

``` python
["apple", "banana", "orange"]
```

------------------------------------------------------------------------

## Очень важное различие типов

`split()` --- это метод **строки**.

Работает:

``` python
text.split(",")
```

Не работает:

``` python
items.split(",")
```

если `items` уже является списком.

Тип объекта определяет, какие методы доступны.

------------------------------------------------------------------------

## Разделитель по умолчанию

``` python
text = "one two three"

items = text.split()
```

Результат:

``` python
["one", "two", "three"]
```

------------------------------------------------------------------------

# `join()`

`join()` объединяет несколько строк в одну.

``` python
items = ["apple", "banana", "orange"]

result = ", ".join(items)
```

Получаем:

``` text
apple, banana, orange
```

------------------------------------------------------------------------

## Ментальная модель

`split()`:

``` text
строка
  ↓
список строк
```

`join()`:

``` text
список строк
  ↓
строка
```

Это противоположные операции.

------------------------------------------------------------------------

## Типичная ошибка

Все элементы должны быть строками.

Такое:

``` python
items = ["Alice", 20]
", ".join(items)
```

вызовет ошибку, потому что `20` --- это `int`.

Необходимо сначала преобразовать данные в строки.

------------------------------------------------------------------------

# `startswith()`

Проверяет, начинается ли строка с указанного текста.

``` python
filename = "image_0001.png"

filename.startswith("image_")
```

Результат:

``` text
True
```

------------------------------------------------------------------------

# `endswith()`

Проверяет окончание строки.

``` python
filename.endswith(".png")
```

Результат:

``` text
True
```

------------------------------------------------------------------------

## Практическое применение

Например:

``` python
if filename.endswith(".png"):
    process_image(filename)
```

# Файловый ввод-вывод

Файл --- один из способов взаимодействия программы с внешним миром.

До этого данные могли существовать:

``` text
в переменной
в списке
в словаре
```

Но после завершения программы эти данные обычно исчезают из памяти.

Файл позволяет сохранить данные вне программы.

------------------------------------------------------------------------

## Общая схема

``` text
Файл
  ↓
чтение
  ↓
Python-объект
  ↓
обработка
  ↓
результат
```

Например:

``` text
tags.txt
   ↓
read()
   ↓
строка
   ↓
split()
   ↓
список тегов
```

------------------------------------------------------------------------

# `open()`

Для открытия файла используется `open()`.

``` python
file = open("data.txt", "r")
```

`"r"` означает режим чтения.

Другие режимы существуют и будут изучаться по мере необходимости.

------------------------------------------------------------------------

## Почему `open()` недостаточно?

После работы с файлом его необходимо корректно закрыть.

Теоретически можно:

``` python
file = open("data.txt", "r")
data = file.read()
file.close()
```

Но в Python предпочтительно использовать контекстный менеджер `with`.

------------------------------------------------------------------------

# `with open()`

Рекомендуемый вариант:

``` python
with open("data.txt", "r") as file:
    data = file.read()
```

После выхода из блока `with` файл корректно закрывается.

------------------------------------------------------------------------

## Ментальная модель

`with` можно воспринимать как:

``` text
Открыть ресурс
      ↓
Использовать ресурс
      ↓
Автоматически освободить ресурс
```

Это особенно полезно для ресурсов, которые обязательно нужно закрывать.

------------------------------------------------------------------------

# `read()`

`read()` читает содержимое файла.

``` python
with open("data.txt", "r") as file:
    data = file.read()
```

Теперь:

``` python
data
```

содержит весь текст файла.

------------------------------------------------------------------------

## Тип результата

При обычном текстовом чтении:

``` python
data
```

будет строкой `str`.

Поэтому после чтения можно использовать строковые методы:

``` python
data.strip()
data.split()
data.replace(...)
```

------------------------------------------------------------------------

# Чтение файла построчно

Файл можно перебирать в цикле:

``` python
with open("data.txt", "r") as file:
    for line in file:
        print(line)
```

Каждая итерация предоставляет очередную строку.

------------------------------------------------------------------------

## Очистка строк

Строки из файла часто содержат символ переноса строки:

``` text
\n
```

Поэтому часто используется:

``` python
with open("data.txt", "r") as file:
    for line in file:
        line = line.strip()
```

Теперь строка очищена от лишних пробелов и символов переноса строки по
краям.

------------------------------------------------------------------------

# Очистка данных на границе системы

Это важный инженерный принцип.

Если данные приходят извне:

``` text
пользователь
файл
API
база данных
```

желательно очистить и нормализовать их **сразу после получения**.

Например:

``` python
raw_name = input("Name: ")
name = raw_name.strip()
```

или:

``` python
with open("tags.txt") as file:
    for line in file:
        tag = line.strip()
        process(tag)
```

Вместо того чтобы заставлять каждую последующую функцию самостоятельно
помнить:

> «А вдруг здесь есть пробелы?»

мы очищаем данные на входе.

# Часть VIII. Инженерные принципы

------------------------------------------------------------------------

# Разделение ответственности

## Что это?

Разделение ответственности означает, что разные части программы отвечают
за разные задачи.

Например, не следует делать одну огромную функцию:

``` text
получить ввод
↓
проверить ввод
↓
прочитать файл
↓
обработать данные
↓
посчитать результат
↓
сохранить файл
↓
вывести интерфейс
```

Лучше разделить:

``` text
get_input()
    ↓
validate_input()
    ↓
process_data()
    ↓
save_result()
```

------------------------------------------------------------------------

## Почему это полезно?

Если что-то сломалось, проще определить место проблемы.

Например:

> Файл неправильно читается.

Не нужно проверять всю программу.

Можно отдельно проверить функцию чтения.

------------------------------------------------------------------------

# Чистка данных на границе системы

Если данные приходят извне, их лучше привести к нормальной форме сразу.

Например:

``` python
name = input("Name: ").strip().lower()
```

После этого остальная программа может предполагать, что:

``` text
name
```

уже очищен.

------------------------------------------------------------------------

## Почему это лучше?

Без такого подхода каждая функция может выглядеть так:

``` python
def process(name):
    name = name.strip()
    name = name.lower()
    ...
```

А другая:

``` python
def validate(name):
    name = name.strip()
    ...
```

Получается дублирование.

Лучше один раз нормализовать данные на входе.

------------------------------------------------------------------------

# Предсказуемость интерфейсов функций

Функция должна иметь понятный контракт.

Например:

``` python
def calculate_total(price, quantity):
    return price * quantity
```

Мы понимаем:

``` text
Вход:
    число
    число

Выход:
    число
```

Плохо, если одна ветка возвращает число:

``` python
return 10
```

а другая:

``` python
return "error"
```

если вызывающий код не рассчитан на такую вариативность.

------------------------------------------------------------------------

# Повторное использование кода

Если один и тот же алгоритм используется в нескольких местах, его можно
вынести в функцию.

Вместо:

``` python
# код №1

# тот же код №2

# тот же код №3
```

создаётся:

``` python
def process_data(data):
    ...
```

и затем:

``` python
process_data(data1)
process_data(data2)
process_data(data3)
```

------------------------------------------------------------------------

## Польза

Изменение алгоритма происходит в одном месте.

------------------------------------------------------------------------

# Читаемость важнее хитрости

Код пишется не только для компьютера.

Его будут читать:

-   ты сам через месяц;
-   другой разработчик;
-   будущая версия тебя;
-   ИИ-ассистент.

Поэтому решение:

``` python
if user_exists and user_is_active:
    ...
```

часто лучше сложного однострочного выражения, которое требует
дополнительного объяснения.

------------------------------------------------------------------------

# Human-in-the-loop

Не каждое решение необходимо или возможно полностью автоматизировать.

Например, программа может определить:

``` text
Файл похож на ненужный.
```

Но вопрос:

> «Можно ли его удалить?»

может требовать человеческого решения.

Поэтому архитектура может выглядеть так:

``` text
Автоматическая классификация
        ↓
Предложение действия
        ↓
Подтверждение человека
        ↓
Выполнение
```

Это называется **human-in-the-loop**.

# Часть IX. Типичные ошибки

------------------------------------------------------------------------

# Путаница между строкой и числом

``` python
age = input("Age: ")
```

`age` --- строка.

Поэтому:

``` python
age + 5
```

некорректно.

Нужно:

``` python
age = int(input("Age: "))
```

------------------------------------------------------------------------

# Путаница между функцией и методом

Правильно:

``` python
len(items)
```

Потому что `len()` --- встроенная функция.

Правильно:

``` python
items.append("Apple")
```

Потому что `append()` --- метод списка.

------------------------------------------------------------------------

# Путаница типов при работе с коллекциями

Например:

``` python
items = ["one", "two", "three"]
```

Можно:

``` python
items.append("four")
```

Но:

``` python
items.split(",")
```

нельзя.

`split()` относится к строкам.

------------------------------------------------------------------------

# Забытый `return`

Проблема:

``` python
def add(a, b):
    result = a + b
```

Здесь результат вычисляется, но не возвращается.

Поэтому:

``` python
result = add(2, 3)
```

получит:

``` python
None
```

Правильно:

``` python
def add(a, b):
    return a + b
```

------------------------------------------------------------------------

# Несогласованное количество возвращаемых значений

Проблемный код:

``` python
def get_user(data):
    if not data:
        return None

    return name, age
```

Здесь разные ветви возвращают разные структуры.

Лучше обеспечить единый контракт.

Например:

``` python
def get_user(data):
    if not data:
        return None, None

    return name, age
```

------------------------------------------------------------------------

# Неправильная работа с индексами

Список:

``` python
items = ["A", "B", "C"]
```

имеет индексы:

``` text
0
1
2
```

Поэтому:

``` python
items[3]
```

некорректно.

Если нужен элемент и индекс одновременно:

``` python
for index, item in enumerate(items):
    ...
```

------------------------------------------------------------------------

# Путаница между `append()` и `extend()`

`append()` добавляет **один объект**:

``` python
items = [1, 2]

items.append([3, 4])
```

Результат:

``` python
[1, 2, [3, 4]]
```

Список `[3, 4]` стал одним элементом.

`extend()` добавляет элементы другой коллекции:

``` python
items = [1, 2]

items.extend([3, 4])
```

Результат:

``` python
[1, 2, 3, 4]
```

------------------------------------------------------------------------

# Ожидание изменения строки на месте

Неправильно:

``` python
text = "hello"

text.upper()

print(text)
```

Получим:

``` text
hello
```

Потому что строки неизменяемы.

Правильно:

``` python
text = text.upper()
```

------------------------------------------------------------------------

# Неправильное использование `sort()`

`sort()` изменяет список и не возвращает отсортированный список.

Поэтому:

``` python
numbers = [3, 1, 2]

result = numbers.sort()
```

даст:

``` text
result → None
```

Правильно:

``` python
numbers.sort()
```

или:

``` python
result = sorted(numbers)
```

``` python
{}
```

--- это пустой словарь.

Пустое множество:

``` python

```

Документ является **живым справочником**.

По мере прохождения следующих модулей новые знания должны добавляться в
соответствующие существующие разделы, а не просто приклеиваться в конец
документа.

Если новая концепция относится к уже существующей категории, она должна
расширять соответствующий раздел.

Если концепция требует нового уровня абстракции, для неё следует создать
новый раздел.

Главная цель Handbook:

> **В любой момент позволить студенту самостоятельно восстановить
> знания, необходимые для решения задачи, без обращения к интернету или
> преподавателю.**
